# Changelog

## 0.0.2 — Unreleased

- Add an explicit **Save temporary text** setting for Granola and other dictation apps that publish `TransientType` text. It is off by default; concealed/password-marked content and temporary non-text formats stay excluded.
- Capture non-sensitive third-party autogenerated text. Use a SuperCopy-specific replay marker to prevent recapturing restored entries.
- Retry text that arrives after clipboard formats are declared, including initially empty revisions. Metadata alone no longer creates an empty history entry.
- Retry temporary save failures instead of permanently discarding the current copy. Retry work is bounded to eight attempts per revision; explicit policy changes restart it.
- Restore monitor operation after stop/start.
- Keep concealed text hidden in the picker even when autogenerated markers are also present.
- Isolate test capture preferences from the installed app's pause/exclusion settings.

## 0.0.1 — 2026-11-16

Initial developer preview with local history, hold/cycle/release paste, local search and OCR, universal DMG packaging, and version/build information in Settings.
