# Security

Clipboard history may contain secrets even when it never leaves the machine. Do not post private clipboard data, history databases, or exploit payloads in public issues.

Report vulnerabilities privately through [GitHub's security reporting](https://github.com/desenyon/SuperCopy/security/advisories/new). If private reporting is unavailable, contact the maintainer through the profile linked from the repository rather than opening a public report with details.

The current maintained line is 1.0.x. There is no guarantee of a particular response time. Local self-signed builds are for development and personal use; release signing must use the distributor's own Apple identity.

See [Privacy](docs/PRIVACY.md) for storage, permissions, and deletion behavior.
