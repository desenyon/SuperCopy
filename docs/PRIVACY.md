# Privacy

SuperCopy has no account, server, analytics, advertising, crash-upload SDK, or application network client. Clipboard content, search vectors, image OCR, copied-file archives, and settings stay on the Mac. Apple's system services may have their own network behavior; SuperCopy does not upload history to them.

History lives in `~/Library/Application Support/SuperCopy/`. The directory is restricted to the current user. There is no separate database encryption; FileVault protects the disk at rest. macOS backups may include this directory.

SuperCopy saves clipboard representations exposed by source apps: text, images, audio data, file URLs, and custom formats. It archives readable copied files and folders so they can survive source deletion. It does not record the microphone or screen. Audio is not transcribed. Image OCR and English sentence embeddings run locally when the system models are available.

Accessibility permits global keyboard interception and synthetic paste. Only the paste gesture is retained as state; typed keys are not logged. Source app names come from the frontmost app when capture occurs. Secure keyboard input disables interception. Some macOS versions can separately restrict clipboard reads; SuperCopy cannot bypass system privacy decisions.

Concealed, sensitive, transient, and autogenerated pasteboard markers are excluded. Unmarked passwords can still be saved. Pause history or exclude private apps by bundle ID in Settings. Exclusions are based on the frontmost app, which may differ from the actual copy source in automation or background workflows.

Use **Clear history** to delete saved entries and archives. This keeps the current clipboard intact. A restored-file lease may remain while the clipboard references it; it is pruned after the clipboard changes and the app can check again. Deleting files is not a promise of forensic erasure on APFS or in backups.

The bundled privacy manifest declares no tracking and no data collection off-device. Required-reason API entries cover app preferences, local/copied-file timestamps, and elapsed time used for delivery timers. A future store listing must be checked against the exact submitted binary.
